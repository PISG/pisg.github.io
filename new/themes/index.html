Themes

One line of config changes how the whole page looks.

<set ColorScheme="modern"> is the entire change. Four modern schemes ship with 1.0a, the eight classic ones are untouched — and if none of them is right, the creator further down this page will build yours in a couple of minutes.

Write your own

A theme is one CSS file. That is the whole mechanism.

pisg writes plain HTML with stable class names and drops your stylesheet into the page. There is no template language, no build step and nothing to learn beyond CSS.

making a theme by hand
1
cp layout/modern.css layout/mytheme.css
Start from whichever shipped theme is closest. The four modern ones are built from a single palette at the top of the file, so in most cases the sixteen --variables are the only lines you need to touch.
2
<set ColorScheme="mytheme">
Put that in pisg.cfg and run pisg. The name is the file name in layout/ without .css. Give a path or a URL instead and pisg links to it rather than embedding it; "none" writes the body only, for pasting into a page of your own. See ColorScheme and CssDir.
3
python3 layout/build-themes.py
Optional. The modern schemes are generated from one stylesheet with a palette per theme, so adding yours to that script keeps every theme in step when the stylesheet changes. Edit the palette table at the top, run it, and your CSS file is written with the others.
The sixteen variables. Everything else in the file is layout. --bg, --fg, --muted, --card, --row, --row-alt, --line, --accent, --head, the four time-of-day colours --blue (night), --green (morning), --yellow (afternoon), --red (evening), then --male, --female and --shadow.
Keep the four time-of-day colours distinguishable from each other: they are the bars in most active times, daily activity and the relation map, and they are the one place where colour carries meaning rather than decoration. The creator below shows the contrast figures as you go.
