    #What ships

    Four schemes came with 1.0a and eight have been in the box since the SourceForge days. <set ColorScheme="modern"> in pisg.cfg is the whole change. The sample pages are real pisg 1.0a output, every section included, made from an invented channel — forty made-up regulars over two months — so nobody real is in them.

    The eight classics, brought forward

    The old schemes still work exactly as they always did — <set ColorScheme="ocean"> and you get the page you remember. They have also been converted to the 1.0a palette, so you can have the classic colours with the new layout and the new sections: pick one in the sidebar and download it. The conversion keeps each theme's own link colour, headline colour and its four bar colours — read straight out of the sprite each file carries — and lifts anything that would not have read on the new layout.

    #Write your own, by hand

    A theme is one CSS file. pisg writes plain HTML with stable class names and drops your stylesheet into the page — no template language, no build step, nothing to learn beyond CSS. The creator above is a convenience, not a requirement.

    making a theme by hand
    1
    cp layout/modern.css layout/mytheme.css
    Start from whichever theme is closest. The modern ones are built from a single palette at the top of the file, so in most cases the sixteen --variables are the only lines you need to touch.
    2
    <set ColorScheme="mytheme">
    Put that in pisg.cfg and run pisg. The name is the file name in layout/ without .css. Give a path or a URL instead and pisg links to it rather than embedding it; "none" writes the body only, for pasting into a page of your own. See ColorScheme and CssDir.
    3
    python3 layout/build-themes.py
    Optional. The modern schemes are generated from one stylesheet with a palette per theme, so adding yours to that script keeps every theme in step when the stylesheet changes.
    The sixteen variables. Everything else in the file is layout. --bg, --fg, --muted, --card, --row, --row-alt, --line, --accent, --head, the four time-of-day colours --blue (night), --green (morning), --yellow (afternoon), --red (evening), then --male, --female and --shadow.
    Keep the four time-of-day colours distinguishable from each other: they are the bars in most active times, daily activity and the relation map, and the one place where colour carries meaning rather than decoration. The sidebar checks that as you go.
